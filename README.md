# Review Assistent

Десктопный ассистент для созвонов и собеседований (Windows, macOS, Linux). Во время разговора он:

- распознаёт речь в реальном времени — вашу (микрофон) и собеседников (системный звук), разделяя собеседников по голосу;
- по вашей команде — ключевой фразе вроде «хороший вопрос» или горячей клавише — формулирует заданный вопрос и сразу пишет короткий ответ;
- показывает вопрос и ответ в полупрозрачном оверлее поверх всех окон, который **не попадает в демонстрацию экрана и запись** (на Windows; на macOS — частично, на Linux — нет, см. [macOS и Linux](#macos-и-linux));
- добавляет к вопросу скриншот экрана (схема, код для лайвкодинга), чтобы ответ учитывал то, что на нём;
- записывает аудио, видео выбранного экрана или окна и сохраняет всё в папку сессии.

## Требования

- **Windows 10 или 11.** Системный звук захватывается через WASAPI loopback, защита оверлея от захвата экрана работает на Windows 10 2004 и новее.
- **macOS 14.2+** (Apple Silicon или Intel) — системный звук через CoreAudio. Особенности — в разделе [macOS и Linux](#macos-и-linux).
- **Linux** с PipeWire (или PulseAudio) — например, Bazzite / Fedora с KDE Plasma. Без защиты оверлея от захвата экрана, см. [macOS и Linux](#macos-и-linux).
- **Node.js 22+ и npm** — для запуска из исходников и сборки.
- **Ключ Deepgram** — для распознавания речи.
- **Ключ LLM-провайдера** — для вопросов и ответов: Anthropic (Claude), Google (Gemini) или любой OpenAI-совместимый сервис (OpenAI, OpenRouter, Selectel и т. п.). Можно указать свой адрес совместимого шлюза.
- Доступ в интернет к Deepgram и выбранному LLM.

## Установка и запуск

```bash
npm install          # зависимости + скачивание ONNX-моделей в resources/models
npm run dev          # запуск в режиме разработки
```

`npm install` сам скачивает две модели (детектор речи Silero VAD и модель голосов ERes2Net для разделения собеседников). Если загрузка не удалась, запустите её повторно:

```bash
npm run models
```

Без моделей приложение работает, но хуже: вместо Silero используется простой детектор речи по громкости, а собеседники разделяются средствами Deepgram.

Сборка установщика для текущей системы (папка `dist`): NSIS на Windows, dmg на macOS, AppImage на Linux. Нативные модули ставятся под ту систему и архитектуру, где выполнялся `npm install`, поэтому собирайте там же, где будете запускать.

```bash
npm run dist
```

> **Важно при `npm run dev`:** изменения в окнах подхватываются на лету, а главный процесс — нет. После обновления кода (`git pull`) или правок в `src/main`, `src/pipeline`, `src/shared` перезапустите `npm run dev`, иначе возможны ошибки вроде «Неизвестный провайдер».

Приложение работает в одном экземпляре: повторный запуск просто открывает окно управления. Закрытие или сворачивание окна прячет его в трей; выход — через меню трея.

## macOS и Linux

Что отличается от Windows. Окно управления показывает предупреждения для текущей системы в карточке «Особенности системы».

### macOS

- **Разрешения.** При первом запуске macOS спросит доступ к микрофону, к записи экрана и к системному аудио (для звука собеседников, видео и скриншотов). Если после выдачи разрешения на запись экрана скриншоты пустые, перезапустите приложение. Изменить решение можно в «Системные настройки → Конфиденциальность и безопасность» («Микрофон», «Запись экрана и системного аудио»). При `npm run dev` разрешения выдаются приложению Electron.
- **Защита оверлея — частичная.** macOS скрывает окно только от старых способов захвата. Программы на ScreenCaptureKit (на macOS 15 и новее — почти все программы для звонков и записи) оверлей **видят**. Перед созвоном проверьте демонстрацию экрана в вашей программе; если оверлей виден, скрывайте его (⌃⌥O) на время демонстрации.
- **Горячие клавиши** — ⌃⌥ (Control+Option) вместо Ctrl+Alt: сочетания ⌘⌥ заняты Finder и другими программами.
- **Значок** — в строке меню; в Dock приложение видно, пока открыто окно управления.
- **Сборка** — `npm run dist:mac`, получается dmg с ad-hoc подписью. При первом открытии: правый клик по приложению → «Открыть» (или `xattr -cr "/Applications/Review Assistent.app"`). После каждой пересборки подпись меняется, и macOS спрашивает разрешения заново. Чтобы раздавать приложение другим, нужны сертификат Developer ID и нотаризация (`mac.identity` в `electron-builder.yml`).

### Linux

- **Системный звук** — loopback устройства вывода по умолчанию через PulseAudio (на PipeWire — через pipewire-pulse, он есть в Fedora и Bazzite).
- **Защиты оверлея от захвата нет**: он виден в демонстрации экрана, записи и скриншотах. Скрывайте его (Ctrl+Alt+O) на время демонстрации.
- **Wayland.** Приложение само перезапускается через XWayland (`--ozone-platform=x11`), иначе оверлей не держится поверх окон и не запоминает положение. Запустить как обычный Wayland-клиент: `REVIEW_ASSISTENT_WAYLAND=1`.
- **Экран и окно на Wayland** выбираются в системном диалоге: он появляется при первом скриншоте или записи видео в сессии, выбор действует до конца сессии. Сменить источник — кнопка «Выбрать источник…» в карточке «Видео и скриншоты».
- **Горячие клавиши на Wayland** регистрируются через системный портал: KDE при первом запуске попросит подтвердить сочетания, поменять их можно в «Параметры системы → Комбинации клавиш».
- **API-ключи** шифруются через KWallet или GNOME Keyring. Если хранилища нет, окно управления предупредит: ключи окажутся почти в открытом виде.
- **Сборка** — `npm run dist:linux`, получается AppImage.
- **Разработка на Bazzite** (система неизменяемая): Node.js удобно поставить в контейнер — `distrobox create -n dev -i fedora:latest`, `distrobox enter dev`, `sudo dnf install nodejs npm`, затем `npm install` и `npm run dev`. Если внутри контейнера Electron падает с ошибкой песочницы, запустите `npx electron-vite dev --noSandbox -- --ozone-platform=x11`.

## Первая настройка

Всё настраивается в окне управления. Ключи хранятся зашифрованными средствами системы (DPAPI на Windows, Связка ключей на macOS, KWallet / GNOME Keyring на Linux) и после сохранения не показываются.

### 1. Распознавание речи (карточка «Транскрибация (Deepgram)»)

1. Вставьте **API-ключ Deepgram** и нажмите «Сохранить».
2. **Модель** — по умолчанию `nova-3`; **язык** — `ru`.
3. **Термины** — английские слова, которые должны распознаваться в русской речи (Kafka, RabbitMQ, Kubernetes…). Подробнее — в разделе [Термины для распознавания](#термины-для-распознавания).

Настройки распознавания применяются со следующей сессии.

### 2. LLM (карточка «Ассистент (LLM)»)

Вверху — вкладки по типу API: **Anthropic-совместимые**, **Google-совместимые**, **OpenAI-совместимые**. Зелёная точка на вкладке — ключ сохранён. В каждой вкладке:

- **Эндпоинт** — «Официальный» или «Свой» (адрес совместимого шлюза; после ввода — «Сохранить»);
- **API-ключ**.

Формат своего адреса:

| Тип API | Официальный адрес | Свой адрес |
|---|---|---|
| Anthropic | `https://api.anthropic.com` | без `/v1`, например `https://api.fastypass.com:8444` |
| Google | `https://generativelanguage.googleapis.com` | без версии в пути |
| OpenAI | `https://api.openai.com/v1` | **с** версией, например `https://api.selectel.ru/aig/v1` — к нему добавляется `/chat/completions` |

Ниже разделителя — какие модели обрабатывают две задачи:

- **Вопрос, саммари** — формулировка вопроса и краткие пересказы длинных реплик. Нужна быстрая модель.
- **Ответы** — генерация ответа. Можно сильнее.

Для каждой задачи выберите тип API, впишите **имя модели** (как его называет провайдер: `claude-opus-5-5`, `gemini-3.8-flash`, `gpt-5`, `anthropic/claude-haiku-5.5`…) и **effort** (`low` / `medium` / `high` — глубина размышлений). Чем выше effort, тем дольше ждать первого слова ответа; для живого разговора обычно хватает `low`.

### 3. Ключевые фразы

В той же карточке — список фраз через запятую. Сказанная **в начале вашей реплики** (в первых шести словах), фраза формирует вопрос и сразу запускает ответ. По умолчанию: «хороший вопрос, отличный вопрос, интересный вопрос, понял ваш вопрос, понял вопрос, дайте подумать, good question, great question, let me think». Регистр, «ё» и знаки препинания не важны. Пустой список — функция выключена. Применяется сразу, даже в идущей сессии.

### 4. Мой контекст

Текст о вас: роль, опыт, стек, текущий проект. Используется в каждом ответе, чтобы ответ звучал от вашего лица и с вашими фактами. Модель не придумывает факты о вас: если ответ зависит от того, чего нет в контексте, она даст общий ответ и отметит, что дополнить.

### 5. Звук и видео

- **Микрофон** — по умолчанию системный.
- **Записывать аудио** — сохранять `audio.webm` (левый канал — вы, правый — собеседники). Нужен, чтобы в видео был звук.
- **Источник для видео и скриншотов** — экран или окно в карточке «Видео и скриншоты». Если не выбран — основной экран.

## Сессия: как пользоваться на созвоне

1. Откройте созвон (Zoom, Meet, Teams, Telegram — что угодно: звук собеседников берётся из системного вывода).
2. Начните сессию: **Ctrl+Alt+S**, кнопка «Начать» или меню трея. В оверлее пойдёт таймер, индикаторы «Я» и «Собеседники» подсвечиваются, когда кто-то говорит.
3. Разговаривайте. В окне управления — живой транскрипт.
4. Когда вам задали вопрос, скажите ключевую фразу («Хороший вопрос…») или нажмите **Ctrl+Alt+Q**. В оверлее появится вопрос, ниже — ответ, который печатается по мере генерации.
5. Остановите сессию: **Ctrl+Alt+S** ещё раз. Файлы финализируются (видео собирается со звуком), и папка сессии открывается в файловом менеджере.

## Вопросы и ответы

### Как формируется вопрос

Вопросы создаются **только по вашей команде** — автоматически приложение вопросы не ищет. Командой служат:

- ключевая фраза в начале вашей реплики;
- **Ctrl+Alt+Q** — «вопрос из фраз после прошлого вопроса + ответ»;
- **Ctrl+Alt+A** и **скриншот** — если вопросов ещё нет.

Каждая команда ставит **метку**. Вопрос составляется из **всех фраз — и собеседника, и ваших — между прошлой меткой и этой**; до первой метки — с начала сессии. Метки идут последовательно, поэтому каждая фраза попадает ровно в один вопрос, и вопросы не склеиваются между собой.

- Фраза относится к той метке, до которой её **начали** говорить — даже если распознавание закончило её позже. Если в момент метки фраза собеседника ещё распознаётся, ассистент ждёт её окончания (до 1,5 с).
- Ваши фразы в окне — уточнения и поправки («вы имеете в виду для API?» — «да, для API»); модель вплетает их в формулировку.
- Если собеседник ничего не говорил, а говорили только вы (зачитали вопрос из чата, повторили неслышный вопрос, озвучили задание), вопрос ищется в ваших словах.
- Ваша фраза с ключевым словом в вопрос не попадает.

Модель формулирует **последний** заданный в окне вопрос; ответы, комментарии и small talk перед ним — только контекст.

### Если вопрос не определился

Вопрос создаётся **всегда**, когда в окне есть фразы. Если модель не нашла в них вопроса или запрос не прошёл, вопрос всё равно появится с пометкой «не определён» — вместо формулировки будут сами фразы (приглушённым курсивом), а ответ сразу не генерируется. Дальше:

- сделайте скриншот (**Ctrl+Alt+P**) — например, если задание показано на экране, или
- дождитесь уточнения от собеседника / уточните сами и нажмите **Ctrl+Alt+A**.

Обе команды заново пробуют сформулировать вопрос и всегда пересчитывают ответ.

### Дополнить вопрос и пересчитать ответ — Ctrl+Alt+A

Берёт **последний** вопрос (даже если в оверлее вы листаете другой), добавляет к нему все фразы, сказанные после его метки, переформулирует и генерирует ответ заново. Если новых фраз нет — просто пересчитывает ответ. Если последний вопрос отклонён или вопросов нет — работает как новая метка.

Пример: собеседник задал вопрос, вы сказали «хороший вопрос», а он продолжил «…и как вы это мониторили?». Нажмите Ctrl+Alt+A — продолжение войдёт в тот же вопрос.

### Навигация и отклонение

- **Ctrl+Alt+↑ / ↓** — предыдущий / следующий вопрос; в оверлее — счётчик «N / M» и кнопки ◀ ▶.
- **Ctrl+Alt+X** — отклонить текущий вопрос: останавливает генерацию ответа, убирает вопрос из оверлея и списка (внизу списка — «Отклонено: N»). Пригодится, если фраза сработала случайно. Отклонение не возвращает фразы: следующая метка всё равно начнётся после метки отклонённого вопроса.
- На вкладке «Вопросы» окна управления у каждого вопроса есть кнопки «В оверлей», «Ответить заново» и «Отклонить».

### Учтите

- Повтор ключевой фразы, пока вы уже отвечаете, создаст новый вопрос из вашего ответа — чаще всего «не определён». Отклоните его через Ctrl+Alt+X.
- Первая метка в длинной сессии отправляет модели всю речь с начала — это дольше.

## Скриншоты

**Ctrl+Alt+P** или кнопка «Скриншот к вопросу» (во время сессии):

1. снимает экран или окно, выбранное в карточке «Видео и скриншоты» (до 1920×1200; оверлей на снимок не попадает);
2. сохраняет `screenshot-NN.png` в папку сессии;
3. как Ctrl+Alt+A — дополняет последний вопрос новыми фразами (или создаёт вопрос; если не было ни одной фразы — «Вопрос по скриншоту»);
4. прикрепляет снимок к вопросу и пересчитывает ответ с учётом экрана.

К вопросу можно приложить несколько снимков, в модель уходят три последних. Для задачи на код ответ начинается с рабочего кода, для схемы — ссылается на её подписи. В оверлее и списке вопросов у таких вопросов значок 📷 с числом снимков.

Свёрнутое окно снять нельзя — будет ошибка «Не удалось снять источник — окно свёрнуто?».

## Оверлей

Полупрозрачное окно поверх всех окон, исключённое из захвата экрана: собеседники в демонстрации и записи его не видят (на Windows; на macOS и Linux — см. [macOS и Linux](#macos-и-linux)). Показывает таймер сессии, индикаторы речи, текущий вопрос, ответ и счётчик вопросов.

- **Перемещение** — за верхнюю полосу; **размер** — за края. Положение запоминается.
- **Показать/скрыть** — Ctrl+Alt+O.
- **Непрозрачность** — Ctrl+Alt+[ и Ctrl+Alt+], слайдер в окне управления или пресеты в трее.
- **Режимы мыши** (Ctrl+Alt+T):
  - *Интерактивный* — оверлей обычное окно: можно выделять и копировать ответ, прокручивать колесом.
  - *Сквозной* — клики проходят насквозь в окно под оверлеем (удобно, когда он лежит поверх созвона). Мышь принимается только над верхней полосой (перетаскивание, кнопки ◀ ▶) и над **полосой прокрутки справа** (колесо и перетаскивание).
- **Прокрутка без мыши** — Ctrl+Alt+PageUp / PageDown, в любом режиме.

Новый вопрос открывается сверху. За генерирующимся ответом оверлей следует, только если вы прокрутили в самый низ, — если читаете выше, текст не «убегает».

## Видеозапись

Карточка «Видео и скриншоты»:

1. Выберите источник — экран или окно (превью; «Обновить список» — если нужного окна нет). Выбор запоминается; переоткрытое окно находится по заголовку.
2. Во время сессии нажмите «Записывать видео» или **Ctrl+Alt+V**. Повторное нажатие останавливает запись; за сессию можно сделать несколько фрагментов (`video-01`, `video-02`…).

Параметры: до 1920×1080, до 30 кадров/с, кодек H.264 (если доступен, иначе VP9). Оверлей в запись не попадает.

При остановке **сессии** ffmpeg вшивает в каждое видео звук разговора (микрофон и системный звук смешиваются в оба уха; видеопоток не перекодируется): получается `video-NN.mp4` (H.264) или `video-NN.webm` (VP9). Для звука должна быть включена запись аудио. Если окно закрыли во время записи, запись остановится с сообщением; свёрнутое окно даёт застывший кадр.

## Окно управления

Карточки сверху вниз:

- **Сессия** — старт/стоп, таймер, состояние обработки, папка текущей сессии, предупреждения (например, если видео не собралось).
- **Рабочая область** с вкладками:
  - *Транскрипт* — распознанный текст с говорящими («Я», S1, S2…);
  - *Реплики* — речь, сгруппированная по говорящим; для длинных реплик — краткий пересказ от LLM;
  - *Вопросы* — все вопросы с ответами, статусами и кнопками.
- **Звук** — микрофон, запись аудио, индикаторы уровня.
- **Видео и скриншоты** — источник, запись, скриншот.
- **Транскрибация (Deepgram)** — ключ, модель, язык, термины, статус по каналам.
- **Ассистент (LLM)** — провайдеры, модели, ключевые фразы, «Мой контекст».
- **Разделение говорящих** — порог сходства голосов.
- **Оверлей** — видимость, режим мыши, непрозрачность.
- **Горячие клавиши** — список и статус каждой: «активна» или «занята другим приложением».

### Термины для распознавания

Русская модель Deepgram без подсказки **пропускает английские слова** целиком: «в чём разница между Kafka и RabbitMQ» превращается в «в чём разница между и». Список терминов это исправляет.

- Пишите термины так, как хотите видеть их в тексте: `RabbitMQ`, а не `Rebbit MQ`.
- Не больше **50** терминов (счётчик «N / 50» у поля). Длинный список размывает подсказку: на тестовой записи 80 терминов распознавались хуже, чем совсем без них. Оптимально 20–50 действительно нужных.
- У Deepgram лимит 500 токенов на все термины вместе; длинные термины (`SELECT FOR UPDATE`, `ASP.NET MVC`) стоят по несколько токенов.
- При сохранении список проверяется в Deepgram (короткий запрос с 0,1 с тишины); при ошибке он не сохраняется, а под полем видна причина.
- Не добавляйте слова, которые и так звучат по-русски («бэклог», «тимлид»).
- Термины работают только с моделями Nova-3 и Flux.

### Разделение говорящих

Собеседники различаются по голосу локально (S1, S2…). Если разные люди попадают под одну метку — сдвиньте ползунок «Порог сходства» вправо; если один человек дробится на несколько — влево. В идущей сессии применяется со следующей фразы и переразмечает уже распознанные.

## Горячие клавиши

Глобальные — работают, даже когда приложение не в фокусе. На macOS вместо Ctrl+Alt — ⌃⌥ (Control+Option), например ⌃⌥S; окно управления показывает сочетания так, как принято в вашей системе.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+S | Старт / стоп сессии |
| Ctrl+Alt+Q | Вопрос из фраз после прошлого вопроса + ответ |
| Ctrl+Alt+A | Дополнить последний вопрос новыми фразами и ответить заново |
| Ctrl+Alt+P | Скриншот к последнему вопросу + ответ |
| Ctrl+Alt+X | Отклонить текущий вопрос |
| Ctrl+Alt+↑ / ↓ | Предыдущий / следующий вопрос |
| Ctrl+Alt+PageUp / PageDown | Прокрутить оверлей |
| Ctrl+Alt+O | Показать / скрыть оверлей |
| Ctrl+Alt+T | Сквозной режим оверлея вкл / выкл |
| Ctrl+Alt+[ / ] | Непрозрачность оверлея − / + |
| Ctrl+Alt+V | Видеозапись старт / стоп |

Если сочетание занято другим приложением, в таблице окна управления оно отмечено как «занята другим приложением». Сочетания можно поменять в `settings.json` (раздел `hotkeys`, формат [Electron Accelerator](https://www.electronjs.org/docs/latest/api/accelerator)) при выключенном приложении.

## Трей

Значок в трее: синий — ожидание, красный — идёт сессия. Клик открывает окно управления. В меню:

- начать / остановить сессию;
- предупреждение, если что-то не так (например, нет ключа);
- дополнить последний вопрос и ответить;
- записывать видео / остановить видеозапись;
- записывать аудио;
- открыть папку текущей сессии / папку всех сессий;
- показывать оверлей, сквозной режим, непрозрачность;
- выход.

## Файлы сессии и где хранятся данные

Данные приложения лежат в `%APPDATA%\review-assistent\` (Windows), `~/Library/Application Support/review-assistent/` (macOS) или `~/.config/review-assistent/` (Linux):

| Путь | Что это |
|---|---|
| `sessions\ГГГГ-ММ-ДД_чч-мм-сс\` | папка сессии |
| `settings.json` | настройки |
| `secrets.json` | API-ключи, зашифрованные системой (DPAPI, Связка ключей, KWallet / GNOME Keyring): расшифровать их можно только под вашей учётной записью |
| `context.md` | «Мой контекст» |

Состав папки сессии:

| Файл | Содержимое |
|---|---|
| `transcript.jsonl` | распознанные фразы с временем и говорящим, исправления разметки |
| `questions.jsonl` | вопросы, ответы и пересказы реплик (по мере изменения) |
| `audio.webm` | стерео-запись: левый канал — вы, правый — собеседники |
| `video-NN.mp4` / `.webm` | видеофрагменты со звуком разговора |
| `screenshot-NN.png` | скриншоты |
| `session.json` | метаданные: время начала и конца, смещения аудио, видео и скриншотов относительно начала сессии |

Время в `transcript.jsonl` и `questions.jsonl` — миллисекунды от начала сессии; `session.json` позволяет сопоставить их с аудио и видео.

## Приватность

- **В Deepgram** уходит звук (только речь: тишина отсекается локально).
- **В LLM-провайдер** уходят текст разговора, «Мой контекст» и скриншоты. Если указан свой эндпоинт, всё это и ключ проходят через этот шлюз — используйте только те, которым доверяете.
- Разделение собеседников по голосу, детектор речи, запись аудио и видео работают локально.
- Ключи хранятся зашифрованными средствами системы.
- Оверлей скрыт от захвата экрана (полностью — только на Windows), а окно управления — нет: если демонстрируете весь экран, держите его свёрнутым.

## Решение проблем

**«Неизвестный провайдер», ключ или эндпоинт не сохраняются**
Главный процесс запущен со старым кодом. Перезапустите `npm run dev`.

**Английские слова пропадают из транскрипта**
Добавьте их в «Термины» (см. [Термины для распознавания](#термины-для-распознавания)).

**Распознавание не подключается («не удалось подключиться… проверьте API-ключ, модель, язык и термины»)**
Проверьте ключ Deepgram; пересохраните термины — проверка покажет, что не так (часто это лимит в 500 токенов или модель не Nova-3).

**Ответ приходит долго**
Время складывается из размышления модели до первого слова и печати текста. Поставьте для ответов effort `low`, выберите модель быстрее, проверьте шлюз: разные шлюзы с одной и той же моделью различаются в разы.

**«Нет API-ключа: … для вопросов и саммари / ответов»**
Для типа API, выбранного в задаче, не сохранён ключ — откройте его вкладку в карточке «Ассистент».

**«Модель или эндпоинт не найдены — проверьте модель и адрес (…/v1)»** (OpenAI-совместимые)
Адрес должен заканчиваться версией API (`…/v1`), имя модели — как в списке провайдера (у агрегаторов — с префиксом, например `anthropic/claude-haiku-5.5`).

**Скролл в оверлее не работает**
Включён сквозной режим: прокручивайте над полосой прокрутки справа или клавишами Ctrl+Alt+PageUp / PageDown.

**Горячая клавиша «занята другим приложением»**
Освободите сочетание в другой программе или поменяйте его в `settings.json`.

**Нет звука собеседников**
Звук берётся из системного устройства вывода по умолчанию — проверьте, что созвон играет именно в него.

**В видео нет звука**
Включите «Записывать аудио» до начала сессии. Звук вшивается при остановке сессии, а не видеозаписи.

**«Не удалось снять источник — окно свёрнуто?»**
Разверните окно, выбранное источником, или выберите экран.

**Linux: горячие клавиши работают, только когда приложение в фокусе**
Значит, сочетания не дошли до портала и перехватываются через XWayland. В параметрах KDE найдите «Поддержка устаревших приложений X11» (Legacy X11 App Support) и разрешите приложениям X11 читать клавиши, нажатые вместе с Control, Alt или Meta.

**Linux: в сквозном режиме оверлей не ловит мышь над верхней полосой**
Под XWayland положение курсора над чужими окнами может не обновляться. Переключите режим горячей клавишей Ctrl+Alt+T, передвиньте оверлей и включите сквозной режим обратно.

**Ключевая фраза не срабатывает**
Она должна прозвучать в первых шести словах вашей реплики и быть распознана — проверьте транскрипт. Список фраз — в карточке «Ассистент».

## Для разработчиков

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск в режиме разработки |
| `npm run build` | проверка типов + сборка в `out/` |
| `npm run dist` | сборка установщика для текущей системы в `dist/` (явно: `dist:win`, `dist:mac`, `dist:linux`) |
| `npm run typecheck` | проверка типов (main/pipeline и renderer) |
| `npm run lint` / `lint:fix` | ESLint |
| `npm run format` / `format:check` | Prettier |
| `npm test` / `test:watch` | тесты (Vitest) |
| `npm run models` | скачать ONNX-модели |

Структура `src/`:

- `main/` — главный процесс Electron: окна, горячие клавиши, трей, сессия и файлы, захват экрана, ffmpeg, настройки и ключи; `platform.ts` — различия Windows, macOS и Linux.
- `pipeline/` — отдельный процесс обработки: детектор речи, Deepgram, разделение собеседников, реплики, ассистент (вопросы, ответы) и LLM-бэкенды (`llm/claude.ts`, `llm/gemini.ts`, `llm/openai.ts`).
- `renderer/` — интерфейс: `control` (окно управления), `overlay`, `capture` (скрытое окно захвата аудио и видео).
- `preload/` — мост IPC для окон.
- `shared/` — общие типы и контракты IPC.
